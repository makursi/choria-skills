# 主规范（唯一事实源）

来源：本仓库 `apps/document-style-guide`（fork 自 ruanyf/document-style-guide，公共领域）。6 个模块，规则 ID 前缀：`T`（标题）、`X`（文本）、`P`（段落）、`N`（数值）、`M`（标点）、`S`（文档体系）。

**严重级**：

- **错误**：确定性违规，必须修正。
- **警告**：语义/风格问题，通常应修正，需要判断。
- **建议**：可放宽项，改不改均可，但同篇必须一致。

校对时每条规则都必须明确判定（通过/违规），不允许跳过。判定依据以本文件为准；外部指南只作溯源背景（见 provenance.md），不进入判定。

## T 标题

### T1 四级层级
- 严重级：参考（结构定义）
- 要求：标题分四级：一级=文章标题，二级=主要部分大标题，三级=二级下的小标题，四级=三级下某一方面的小标题。

### T2 标题不跳级
- 严重级：错误
- 要求：层级只能逐级下降；一级标题下不能直接出现三级标题。
- 怎么查：扫描标题层级序列，相邻标题级别差 > 1 即违规。
- 错误：

  ```markdown
  # 一级标题

  ### 三级标题
  ```

- 正确：

  ```markdown
  # 一级标题

  ## 二级标题

  ### 三级标题
  ```

### T3 无孤立编号
- 严重级：警告
- 要求：避免孤立编号——同级标题只有一个时，可以并入上级或删除。
- 怎么查：同级标题计数为 1 时提示。
- 示例（`二级标题 A` 下只有一个三级标题，可省略）：

  ```markdown
  ## 二级标题 A

  ### 三级标题 A

  ## 二级标题 B
  ```

### T4 下级不重名
- 严重级：建议
- 要求：下级标题不重复上一级标题的名字。
- 错误：

  ```markdown
  ## 概述

  ### 概述
  ```

### T5 慎用四级标题
- 严重级：建议
- 要求：尽量避免四级标题，保持层级简单；三级标题下有并列内容时，用项目列表或加粗编号，不用四级标题。四级标题只用于较长篇幅的内容。
- 示例（结构二优于结构一）：

  ```markdown
  ### 三级标题

  **（1）A**

  **（2）B**

  **（3）C**
  ```

## X 文本

### X1 中英之间留空格
- 严重级：错误
- 要求：全角中文字符与半角英文字符之间，应有一个半角空格。
- 怎么查：匹配 `[\u4e00-\u9fa5][A-Za-z]` 或 `[A-Za-z][\u4e00-\u9fa5]`（无空格相邻）。
- 错误：`本文介绍如何快速启动Windows系统。`
- 正确：`本文介绍如何快速启动 Windows 系统。`

### X2 中数之间风格统一
- 严重级：警告（仅当同篇混用两种风格时）
- 要求：全角中文字符与半角阿拉伯数字之间，加不加半角空格均可，但全篇必须统一，不能两种风格混杂。半角百分号视同阿拉伯数字。
- 怎么查：同篇出现 `2011年5月` 与 `2011 年 5 月` 两种写法即违规（混用）；只出现一种则通过。
- 正确（二选一，全篇一致）：

  ```
  2011年5月15日，我订购了5台笔记本电脑与10台平板电脑。

  2011 年 5 月 15 日，我订购了 5 台笔记本电脑与 10 台平板电脑。
  ```

- 正确：`今年我国经济增长率是6.5%。` / `今年我国经济增长率是 6.5%。`

### X3 数字与单位之间留空隙
- 严重级：错误
- 要求：英文单位若不翻译，单位前的阿拉伯数字与单位符号之间留出适当空隙。
- 正确：`一部容量为 16 GB 的智能手机`
- 正确：`1 h = 60 min = 3,600 s`

### X4 半角字符与全角标点之间不留空格
- 严重级：错误
- 要求：半角英文字符和半角阿拉伯数字，与全角标点符号之间不留空格。
- 错误：`他的电脑是 MacBook Air 。`
- 正确：`他的电脑是 MacBook Air。`

### X5 控制句长
- 严重级：40 字以上=错误；30～39 字=警告（须语义明确）；20～29 字=通过；20 字以内=最佳
- 要求：不含标点的单句或逗号分隔的句子构件尽量 ≤20 字；逗号分隔的长句总长 ≤100 字或正文 3 行。
- 怎么查：按逗号拆分统计每段字数；单句超 40 字必违规。
- 错误：

  ```
  本产品适用于从由一台服务器进行动作控制的单一节点结构到由多台服务器进行动作控制的并行处理程序结构等多种体系结构。
  ```

- 正确：

  ```
  本产品适用于多种体系结构。无论是由一台服务器（单一节点结构），还是由多台服务器（并行处理结构）进行动作控制，均可以使用本产品。
  ```

### X6 简单句优先
- 严重级：警告
- 要求：尽量使用简单句和并列句，避免使用复合句。
- 并列句：`他昨天生病了，没有参加会议。`
- 复合句（避免）：`那个昨天生病的人没有参加会议。`

### X7 肯定句优先
- 严重级：警告
- 要求：同样一个意思，尽量使用肯定句表达，不使用否定句表达。
- 错误：`请确认没有接通装置的电源。`
- 正确：`请确认装置的电源已关闭。`

### X8 避免双重否定
- 严重级：错误
- 要求：不得使用双重否定句。
- 错误：`没有删除权限的用户，不能删除此文件。`
- 正确：`用户必须拥有删除权限，才能删除此文件。`

### X9 主动语态优先
- 严重级：警告
- 要求：尽量不使用被动语态，改用主动语态。
- 错误：`假如此软件尚未被安装，`
- 正确：`假如尚未安装这个软件，`

### X10 不用非正式语言
- 严重级：警告
- 要求：不使用非正式的语言风格（网络用语、夸张感叹等）。
- 错误：`Lady Gaga 的演唱会真是酷毙了，从没看过这么给力的表演！！！`
- 正确：`无法参加本次活动，我深感遗憾。`

### X11 用现代汉语常用词
- 严重级：警告
- 要求：不使用冷僻、生造或文言文的词语，使用现代汉语的常用表达。
- 错误：`这是唯二的快速启动的方法。`
- 正确：`这是仅有的两种快速启动的方法。`

### X12 用对"的、地、得"
- 严重级：错误
- 要求：定语用"的"，状语用"地"，补语用"得"。
- 正确：`她露出了开心的笑容。`（形容词＋的＋名词）
- 正确：`她开心地笑了。`（副词＋地＋动词）
- 正确：`她笑得很开心。`（动词＋得＋副词）

### X13 代词指代唯一
- 严重级：错误
- 要求：使用代词（"其""该""此""这"等）时必须明确指代内容，保证只有一个含义。
- 错误：`从管理系统可以监视中继系统和受其直接控制的分配系统。`
- 正确：`从管理系统可以监视两个系统：中继系统和受中继系统直接控制的分配系统。`

### X14 名词前形容词不过多
- 严重级：警告
- 要求：名词前不要使用过多的形容词（一长串定语）。
- 错误：`此设备的使用必须在接受过本公司举办的正式的设备培训的技师的指导下进行。`
- 正确：`此设备必须在技师的指导下使用，且指导技师必须接受过由本公司举办的正式设备培训。`

### X15 英文复数还原单数
- 严重级：警告（仅翻译场景）
- 要求：英文原文使用复数形式时，翻译成中文应还原为单数形式。
- 英文：`...information stored in random access memory (RAMs)...`
- 中文：`⋯⋯存储在随机存取存储器（RAM）里的信息⋯⋯`

### X16 外文缩写用半角圆点
- 严重级：错误
- 要求：外文缩写可使用半角圆点（`.`）表示缩写。
- 正确：`U.S.A.`、`Apple, Inc.`

### X17 省略号转中文
- 严重级：错误
- 要求：中文语境中，英文省略号（`...`）应改为中文省略号（`⋯⋯`）。
- 英文：`5 minutes later...`
- 中文：`5 分钟过去了⋯⋯`

### X18 译名用书名号
- 严重级：错误
- 要求：英文书名或电影名改用中文表达时，双引号应改为书名号。
- 英文：`He published an article entitled "The Future of the Aviation".`
- 中文：`他发表了一篇名为《航空业的未来》的文章。`

### X19 首次出现标注中文
- 严重级：警告
- 要求：第一次出现英文词汇时，在括号中给出中文标注；此后再次出现时直接使用英文缩写即可。
- 正确：`IOC（International Olympic Committee，国际奥林匹克委员会）。这样定义后，便可以直接使用"IOC"了。`

### X20 专有名词大小写
- 严重级：错误
- 要求：专有名词中每个词第一个字母大写；非专有名词不需要大写。
- 正确（专有名词）：`American Association of Physicists in Medicine`（美国医学物理学家协会）
- 正确（非专有名词）：`online transaction processing`（在线事务处理），不应大写。

## P 段落

### P1 一段一主题
- 严重级：警告
- 要求：一个段落只能有一个主题或一个中心句子；中心句放在段首概括全段，后面句子为中心句服务。

### P2 段落长度
- 严重级：超过 7 行=错误；5～7 行=警告；最佳 ≤4 行
- 要求：段落长度不能超过七行，最佳段落长度小于等于四行。

### P3 陈述肯定语气
- 严重级：警告
- 要求：段落句子使用陈述和肯定语气，避免感叹语气。

### P4 段间空行
- 严重级：错误
- 要求：段落之间使用一个空行隔开。

### P5 段首不留空白
- 严重级：错误
- 要求：段落开头不要留出空白字符（行首空格/全角空格）。

### P6 引用注明出处
- 严重级：警告
- 要求：
  - 引用第三方内容时注明出处：`One man's constant is another man's variable. — Alan Perlis`
  - 全篇转载：在全文开头显著位置注明作者和出处，并链接原文：`本文转载自 WikiQuote`
  - 使用外部图片：在图片下方或文末标明来源：`本文部分图片来自 Wikipedia`

## N 数值

### N1 数字用半角
- 严重级：错误
- 要求：阿拉伯数字一律使用半角形式，不得使用全角形式。
- 怎么查：匹配全角数字 `[０-９]`。
- 错误：`这件商品的价格是１０００元。`
- 正确：`这件商品的价格是 1000 元。`

### N2 千分号
- 严重级：4 位以上缺千分号=错误；4 位写法不统一=警告
- 要求：4 位以上数值应添加千分号（半角逗号）；4 位数值千分号可选，但全篇统一。
- 正确：`XXX 公司的实收资本为 ￥1,258,000 人民币。`
- 4 位：`1000` 与 `1,000` 均可，但同篇只选一种。

### N3 货币写法
- 严重级：警告
- 要求：货币用阿拉伯数字，并在数字前写出货币符号，或在数字后写出货币中文名称。
- 正确：`$1,000` 或 `1,000 美元`
- 英文货币名称建议参考 ISO 4217。

### N4 数值范围
- 严重级：警告
- 要求：数值范围用波浪线（`～`）或一字线（`—`）连接（连接号规则见 M14）；带有单位或百分号时，两个数字建议都加上单位或百分号。
- 正确：`132 kg～234 kg`、`67%～89%`

### N5 增减表述
- 严重级："降低/减少 N 倍"=错误；"增加了/到"、"降低了/到" 用反=错误；其余=通过
- 要求：数字增加用"增加了"（增量）或"增加到"（定量）；数字减少用"降低了"（增量）或"降低到"（定量）。不得使用"降低 N 倍"或"减少 N 倍"。
- 正确：`增加到过去的两倍`（过去为一，现在为二）
- 正确：`增加了两倍`（过去为一，现在为三）
- 正确：`降低到百分之八十`（定额是一百，现在是八十）
- 正确：`降低了百分之八十`（原来是一百，现在是二十）
- 错误：`降低了一倍`（减少一倍表示数值原来为一百，现在等于零）

## M 标点

### M1 全角/半角标点
- 严重级：错误
- 要求：中文语句的标点一律用全角；整句为英文时，该句用半角标点。
- 怎么查：中文句中出现半角 `,` `.` `?` `!`（成句结尾）即违规；整句英文中出现全角标点即违规。

### M2 点号不出现在行首
- 严重级：错误
- 要求：句号、问号、叹号、逗号、顿号、分号和冒号不得出现在一行之首。
- 怎么查：行首出现 `。` `？` `！` `，` `、` `；` `：` 即违规。

### M3 标题末尾的标点
- 严重级：错误
- 要求：点号（句号、逗号、顿号、分号、冒号）不得出现在标题末尾；标号（引号、括号、破折号、省略号、书名号、着重号、间隔号、叹号、问号）可以。

### M4 句号位置
- 严重级：错误
- 要求：句子末尾用括号加注时，句号应在括号之外。
- 错误：`关于文件的输出，请参照第 1.3 节（见第 26 页。）`
- 正确：`关于文件的输出，请参照第 1.3 节（见第 26 页）。`

### M5 避免一逗到底
- 严重级：警告
- 要求：逗号表示句子内部的一般性停顿；整个段落除结尾外全部停顿都用逗号即"一逗到底"，应避免。改用分号、句号拆分。

### M6 顿号与并列
- 严重级：错误（中文句并列词用逗号分隔）；警告（未用"和/以及"连接最后一项）
- 要求：
  - 中文句子内部的并列词用全角顿号（`、`）分隔，不用逗号——即使并列词是英语。
  - 英文句子中，并列词语之间用半角逗号（`,`）。
  - 中文句并列词，最后一个尽量用"和"（或"以及"）连接。
- 错误：`我最欣赏的科技公司有 Google, Facebook, 腾讯, 阿里和百度等。`
- 正确：`我最欣赏的科技公司有 Google、Facebook、腾讯、阿里和百度等。`
- 更优：`我最欣赏的科技公司有 Google、Facebook、腾讯、阿里，以及百度等。`
- 英文例句：`Microsoft Office includes Word, Excel, PowerPoint, Outlook and other components.`

### M7 分号
- 严重级：参考（定义）
- 要求：分号（`；`）表示复句内部并列分句之间的停顿。

### M8 引号
- 严重级：错误
- 要求：引用使用全角双引号（`“ ”`），注意前后双引号不同；引号内再用引号时，外层双引号、内层单引号（`‘ ’`），注意前后不同。不用直角引号。
- 正确：`许多人都认为客户服务的核心是"友好"和"专业"。`
- 正确：`鲍勃解释道："我要放音乐，可萨利说，'不行！'。"`

### M9 括号
- 严重级：错误
- 要求：补充说明使用全角圆括号（`（）`），括号前后不加空格。
- 正确：`请确认所有的连接（电缆和接插件）均安装牢固。`
- 名称对照：`{ }` 大括号（braces/curly brackets）；`[ ]` 方括号（square brackets）；`< >` 尖括号（angled brackets）；`( )` 圆括号（parentheses）。

### M10 冒号
- 严重级：错误（时间用全角冒号）
- 要求：全角冒号（`：`）用在需要解释的词语后边，引出解释和说明；表示时间时使用半角冒号（`:`）。
- 正确：`请确认以下几项内容：时间、地点、活动名称和来宾数量。`
- 正确：`早上 8:00`

### M11 省略号
- 严重级：错误
- 要求：省略号（`⋯⋯`）表示语句未完或语气不连续；占两个汉字空间、包含六个省略点；不用 `。。。` 或 `...` 等非标准形式；不与"等"一起使用。
- 怎么查：匹配 `。。。`、`...`（中文语境）、`……`（两字三点式）及省略号与"等"同句。
- 错误：`我们为会餐准备了香蕉、苹果、梨…等各色水果。`
- 正确：`我们为会餐准备了各色水果，有香蕉、苹果、梨⋯⋯`
- 正确：`我们为会餐准备了香蕉、苹果、梨等各色水果。`

### M12 感叹号
- 严重级：错误（连用）；警告（不当使用）
- 要求：使用平静语气叙述，尽量避免感叹号；不得多个感叹号连用（`！！`、`!!!`）。

### M13 破折号
- 严重级：错误
- 要求：破折号（`————`）用于进一步解释；占两个汉字的位置；如果只占一个汉字位置，前后留出一个半角空格。
- 正确：`直觉————尽管它并不总是可靠的————告诉我，这事可能出了些问题。`
- 正确：`直觉 —— 尽管它并不总是可靠的 —— 告诉我，这事可能出了些问题。`

### M14 连接号
- 严重级：错误
- 要求：
  - 两个名词的复合、图表编号用直线连接号（`-`），占一个半角字符位置：`氧化-还原反应`、`图 1-1`。
  - 数值范围（日期、时间或数字）用波浪连接号（`～`）或一字号（`—`），占一个全角字符位置；前后两个值都建议加上单位。
  - 波浪连接号也可用汉字"至"代替。
- 正确：`2009 年～2011 年`
- 正确：`周围温度：-20 °C 至 -10 °C`

## S 文档体系

### S1 软件手册结构（骨架参考）
- 严重级：建议
- 要求：软件手册是一部完整的书，建议采用以下结构（[必备] 为应包含部分）：
  - **简介**（Introduction）：[必备] 对产品和文档本身的总体、扼要说明
  - **快速上手**（Getting Started）：[可选] 如何最快速地使用产品
  - **入门篇**（Basics）：[必备] 初级使用教程（环境准备 [必备]、安装 [可选]、设置 [必备]）
  - **进阶篇**（Advanced）：[可选] 中高级开发教程
  - **API**（Reference）：[可选] API 逐一介绍
  - **FAQ**：[可选] 常见问题解答
  - **附录**（Appendix）：[可选]（Glossary 名词解释、Recipes 最佳实践、Troubleshooting 故障处理、ChangeLog 版本说明、Feedback 反馈方式）
- 真实范例：Redux 手册（redux.js.org）、Atom 手册（flight-manual.atom.io）。

### S2 文件名
- 严重级：错误
- 要求（仅当文档以文件形式给出时检查）：
  - 文件名不得含有空格。
  - 文件名必须使用半角字符，不得使用全角字符；中文不能用于文件名。
  - 文件名建议只使用小写字母；`README`、`LICENSE` 等惯例说明文件可以用大写。
  - 文件名包含多个单词时，单词之间用半角连词线（`-`）分隔。
- 错误：`名词解释.md`、`TroubleShooting.md`、`advanced_usage.md`
- 正确：`glossary.md`、`troubleshooting.md`、`advanced-usage.md`
