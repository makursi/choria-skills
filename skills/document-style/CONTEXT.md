# document-style — 中文技术文档校对技能

一个 Agent 技能：按中文技术文档写作规范对用户的中文技术文档进行评估、修改、更新。规范来源为仓库 `apps/document-style-guide`（fork 自 ruanyf/document-style-guide，公共领域）。

## Language

**校对**:
本技能的 leading word：按主规范逐条检查文档并修正违规的整个过程，是评估、修改、更新三个分支共享的检查动作。
_Avoid_: 审校、润色（前者语义重叠，后者指超出规范的自由改写，不是本技能职责）

**主规范**:
唯一事实源 `references/rules.md` 中的全部规则。六个模块，规则 ID 前缀 T/X/P/N/M/S。
_Avoid_: 规则集、检查清单（与主规范同义重复）

**违规**:
文档中违反主规范某条规则的具体位置；携带规则 ID、严重级、原文、改法。
_Avoid_: 问题、错误（错误只是三种严重级之一，不能指代全部违规）

**严重级**:
错误（确定性违规，必须改）/ 警告（语义或风格问题，通常应改）/ 建议（可放宽，但同篇须一致）。
_Avoid_: 等级、优先级

**例外清单**:
用户声明的明确豁免项（文档 frontmatter 的 `style-exceptions` 或口头声明），只豁免列出的规则 ID 或词条，不接收整体放宽。
_Avoid_: 白名单、豁免规则（含义相同，词面不一致）

**评估**:
默认分支：只输出违规报告，不修改文档。
_Avoid_: 检查（指第 3 步的逐条判定动作，不是分支）

**修改**:
分支：输出修正全文与变更摘要，只修正规范违规，不动技术内容。
_Avoid_: 重写（暗示内容重写，超出规范修正范围）

**更新**:
分支：输入为文件/目录时，按 S2 检查文件名并逐文件落盘修改。
_Avoid_: 编辑、覆盖（不精确）

**溯源注记**:
`references/provenance.md`：主规范之外的外部指南状态与冲突裁决背景，不参与判定。
_Avoid_: 参考资料、背景文件

## Relationships

- **校对** 以 **主规范** 为唯一依据，产出 **违规** 记录
- 一次 **校对** 通过三个分支之一交付：**评估**（报告）、**修改**（全文）、**更新**（落盘）
- **例外清单** 在 **校对** 开始时收集，豁免部分规则的判定
- **主规范** 的"为什么"由 **溯源注记** 解释，但 **溯源注记** 永不参与判定

## Flagged ambiguities

- "修改"曾被理解为内容层面的自由改写。已解决：**修改** 只做规范修正（见规则 X/Y/P/N/M/S 的违规），技术内容、代码、链接、数据保持不变。
- "参考"一词歧义：外部指南是背景（**溯源注记**），不进入判定；判定依据只有 **主规范**。
