# 技能独立仓采用发布渠道模式（集合为真源）

为 notes-refiner 创建独立 GitHub 仓库时，选择了**发布渠道模式**：集合仓（本仓库）始终为唯一真源，独立仓 `makursi/skill-notes-refiner` 只承载运行时文件，供 `skills add` 单独安装；技能改动只发生在集合，发布/同步为手动步骤（见 AGENTS.md 工作流四）。

## Considered Options

- **开发草稿模式**（对称复制 document-style 的收编模式）：集合仍为真源，但独立仓只是影子——既不能安装单技能之外带来什么，还要维护两份心智模型。
- **反转真源**（以后在独立仓开发，集合定期导入）：改写收编模式约定，且 notes-refiner 的开发历史全部在集合内，迁移历史没有收益。

## Consequences

- 每次技能发版后需手动把运行时文件覆盖到独立仓并 commit & push；不写同步脚本（维护约定）。
- 若某技能日后改为在独立仓开发，需新 ADR 取代本条并调整工作流。
